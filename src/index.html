📖 How to Use CyberDM

🌐 Download Files

1. Click + Add URL → Paste any download link → Click Add Download

2. For YouTube/Facebook videos, paste the video page URL — CyberDM auto-detects quality options

3. Select quality (1080p/720p/360p/MP3) → Click Download

🧲 Torrent Downloads

Paste a magnet link into Add URL dialog — CyberDM handles it automatically

🌐 Chrome Extension

1. Go to chrome://extensions in Chrome

2. Enable Developer Mode (top-right toggle)

3. Click Load Unpacked → select the extension folder

4. Visit any website with videos → CyberDM button appears → Click to download

💜 Maya AI Assistant

1. Click the 💜 button (bottom-right corner)

2. Go to Settings → About → Enter your Gemini API Key

3. Chat with Maya, get movie suggestions (🎬), enable voice (🔊)

⚙ Tips

• Speed Limit: Settings → Download → Set KB/s limit (0 = unlimited)

• Auto Resume: Interrupted downloads resume automatically

• Clipboard: Copy any download link — CyberDM catches it instantly
