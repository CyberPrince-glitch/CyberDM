v1.0.4 Architecture & Radical Transparency

No fake marketing promises. Here is what runs in the packaged Windows build today and what is actively on our open-source roadmap.

NEW IN V1.0.4

Duplicate Capture Guard

Repeated captures of the same normalized source URL reuse the existing download record: active jobs aren't duplicated, paused/failed transfers resume, and completed files are skipped if still on disk.

NEW IN V1.0.3

Instant Ready Frame & Lazy Load

Removed the fixed 3.5s splash hold and heavy particle loops. Archive, video conversion, FTP, and SFTP modules lazy-load only when called, while row updates use a cached O(1) row map.

SECURITY & PRIVACY

Scoped Encrypted Cookie Jar

Opt-in browser cookies travel only across local stdio, are encrypted in electron-store, never persist in extension retry queues, and use auto-deleted temp Netscape jars for yt-dlp.

V1.0.2 STABILITY

Crash-Safe Chunk Recovery

Reconciles metadata with on-disk byte lengths on startup, validates HTTP 206 Content-Range & ETag headers, and prevents multi-GB 7-Zip memory spikes during builds.
